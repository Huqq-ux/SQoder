# CourseMate: 从通用智能体到课程学习平台的重新设计

## 背景

现有项目 "Qbot-通用智能体" 是一个基于 LangChain + LangGraph 的通用 AI 智能体系统，技术底子扎实但定位太泛。本设计将项目重新定位为 **CourseMate — 围绕课程教材的 AI 学习伴侣**，聚焦高等教育场景，以课程知识库 + RAG 精准问答 + 学习路径追踪为核心差异化。

## 核心定位

**一句话**：CourseMate 让学生上传课件/教材后，所有 AI 回答严格基于课程材料，同时追踪知识点掌握度。

**核心竞争力三角**：课程 RAG → 学习路径追踪 → 智能笔记生成

**目标用户**：大学生/研究生（学习端）、教师（辅助端，V2）

**项目定位**：个人开源项目，简历展示为主要目的

## 功能集

### P0（MVP 必做）

- **课程知识库**：上传教材/课件（pdf/pptx/docx/epub/xlsx/csv/txt/md），自动按章节建立独立向量索引
- **课程问答**：基于指定课程知识库的问答，引用原文出处（文件名+章节+页码）
- **智能笔记生成**：问答结束后可一键生成该知识点的复习笔记
- **知识图谱**：可视化展示课程各章节/知识点的关联关系

### P1（核心增强）

- **错题本**：自测题错误自动收录
- **学习路径追踪**：知识点掌握度标签（未学/学习中/已掌握）
- **复习计划生成**：根据薄弱点自动生成复习计划
- **论文润色**：上传论文片段，AI 给出学术润色建议

### P2（扩展场景）

- **作业批改**：教师上传标准答案，AI 比对批改
- **代码作业辅导**：编程课作业的 AI 辅导

### V2 留待

- 作业批改系统（等学生端验证后）
- 多模态大模型接入（图片理解，区别于 OCR 纯文字提取）

## 技术架构变更

| 模块 | 说明 |
|------|------|
| Agent 内核 + LangGraph | 核心引擎不变 |
| RAG 管道（FAISS + bge-small-zh-v1.5） | 保留，增强分块策略 |

| SSE 流式响应 | 不变 |

| 模块 | 改动 |
|------|------|

### 删除

| 目标 | 原因 |
|------|------|
| 前端 MultiAgentPage | 能力保留在后端，前端不再暴露 |
| 前端 SkillsPage | 合并到课程设置面板 |
| PowerShell MCP 工具 | Windows 专用，教育场景不需要 |
| `/api/agent-orchestrator` 路由 | 多智能体编排逻辑并入课程 Agent 内部 |

### 新增数据库表

- `courses` — 课程基础信息（名称、学期、描述）
- `knowledge_points` — 知识点（来源分块解析，关联课程）
- `learning_progress` — 学生知识点掌握度
- `notes` — 智能生成的复习笔记
- `wrong_answers` — 错题本

### RAG 数据流

```
上传课件(pptx/pdf/docx/epub)
  → MinerU / python-pptx / python-docx / ebooklib 解析
  → ChapterSplitter（按章节结构分段）
  → 双索引：BM25 关键词索引 + FAISS 向量索引（per-course 隔离）
  → 检索时：BM25 召回 + 向量召回 → 合并去重 → (可选) bge-reranker 精排 → Top-K
  → 问答时只检索本课程的向量空间
```

每个课程独立一个双索引，避免跨课程知识污染。

### 文件类型支持

| 格式 | 优先级 | 技术方案 |
|------|--------|---------|
| .pdf | P0 升级 | MinerU 替换 pypdf（保留公式/表格/阅读顺序） |
| .docx | 已有 | python-docx |
| .txt/.md | 已有 | 内置 |
| .pptx | P0 新增 | python-pptx |
| .xlsx/.csv | P0 新增 | openpyxl + csv |
| .epub | P0 新增 | ebooklib |
| 图片 OCR | P1 | Tesseract/PaddleOCR 提取图片中文字（不依赖大模型） |

### RAG 检索增强

| 增强 | 优先级 | 说明 |
|------|--------|------|
| BM25 + 向量混合检索 | P0 | rank-bm25 做关键词匹配 + FAISS 向量检索，互补召回 |
| MinerU PDF 解析 | P0 | 替换 pypdf，保留表格/公式/阅读顺序 |
| bge-reranker-v2-m3 重排序 | P1 | 粗筛 Top-K 后精排，提升检索命中率 |
| RAGAS 评估框架 | P2 | 量化检索质量（忠实度/召回率/精度），简历加分 |

## 前端重设计

从"通用聊天界面"变为"课程学习工作台"。

### 布局结构

- **左侧栏**：课程列表，每个课程下挂子项（问答/笔记/错题/图谱）
- **主区域顶部**：当前课程名 + 知识点掌握度进度条
- **主区域**：当前激活的功能面板（问答区 / 笔记区 / 知识图谱 / 错题本）

### 核心视图

1. **课程问答**：保留聊天能力，增加引用来源标注（文件名+页码），回答后可一键生成笔记
2. **知识图谱**：可视化课程知识点关联，点击节点跳转问答
3. **学习进度**：章节完成度 + 知识点掌握度仪表盘

## MVP 实施顺序

### 第一轮（课程问答核心闭环）

1. MinerU 替换 pypdf PDF 解析（保留公式/表格/阅读顺序）
2. 新增文件类型（pptx/xlsx/csv/epub）+ 章节分段器
3. BM25 + FAISS 混合检索 + per-course 向量索引
4. 前端改版为课程工作台
5. courses / knowledge_points 表

### 第二轮（学习路径可视化）

5. 知识图谱页面
6. 学习进度追踪
7. 智能笔记生成
8. bge-reranker 重排序（提升检索精度）
9. learning_progress / notes 表

### 第三轮（辅助功能完善）

10. 错题本
11. 复习计划生成
12. 论文润色入口
13. OCR 图片文字提取（Tesseract/PaddleOCR）
14. RAGAS 评估框架接入
15. 旧功能清理

## 决策记录

- **名字**：CourseMate（直观、GitHub 无同名热门项目、国际化友好）
- **领域**：高等教育课程学习
- **差异化**：私有课程知识库 + 学习路径管理（教师协同留待 V2）
- **不做**：K12（需求差异大）、商业化功能（先做开源）、多模态 OCR（等多模态模型）
