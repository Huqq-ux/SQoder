# CourseMate 前端视觉重设计

## 概述

在现有功能 spec（`2026-06-11-coursemate-redesign-design.md`）基础上，对前端进行全面的视觉和交互升级。目标：从"能用的工具"变成"有质感的课程学习工作台"。

## 设计系统

### 双主题

- **暗色主题**：深黑底（#0a0a0f）+ 紫蓝渐变点缀（#6366f1 → #a78bfa），适合长时间学习
- **亮色主题**：浅灰底（#f5f5f7）+ 青绿渐变点缀（#0d9488 → #22d3ee），清新学术感
- 切换按钮位于图标导航栏底部，滑动开关动画，0.4s 全局过渡

### 色彩语义

| 语义 | 颜色 | 用途 |
|------|------|------|
| 主强调 | 紫/青绿（随主题） | 按钮、选中态、链接 |
| 成功/已掌握 | #22c55e | 掌握度标签、进度条 |
| 警告/学习中 | #f59e0b | 学习进度标签 |
| 错误/错题 | #ef4444 | 错题本卡片 |
| 未开始 | 主题强调色 | 未学知识点标签 |

### 动效规范

- **卡片 hover**：上浮 2px + 顶部渐变条展开 + 边框发光 + 阴影增强（0.3s）
- **进度条**：shimmer 流光动画（2s 循环）
- **消息气泡**：fadeInUp 依次淡入（0.4s，交错延迟）
- **主题切换**：所有颜色 0.4s 过渡
- **开关/按钮**：0.2-0.35s cubic-bezier 过渡
- **状态指示灯**：脉冲呼吸动画（2s）

### 质感处理

- 玻璃态选中项（半透明渐变背景 + 细边框）
- 渐变文字（logo、进度百分比）
- 多层次阴影（表面/卡片/hover 三级深度）
- 圆角体系：小元素 8-10px，卡片 10-14px

## 布局架构

### 三栏结构

```
[图标导航 52px] [课程侧栏 260px 可拖拽] [主工作区 flex]
```

- **图标导航**：全局入口（课程/对话/知识库/技能）+ 底部主题切换
- **课程侧栏**：Logo + 课程列表 + 选中课程的子导航（问答/笔记/图谱/错题）+ 底部全局链接（知识库管理/新建课程/设置）
- **主工作区**：可单独滚动

### 路由设计

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 统计卡片 + 课程列表 |
| `/course/:slug` | 课程工作台 | 含问答/笔记/图谱/错题 Tab |
| `/chat` | 通用对话 | 不关联课程的独立对话 |
| `/knowledge` | 知识库管理 | 文档上传 + 文件列表 |
| `/settings` | 设置 | 分类设置面板 |

### 删除页面

- MultiAgentPage、MCPPage — 后端能力保留，前端移除入口
- SkillsPage — 合并到设置页的技能管理分组

## 页面设计

### 首页 `/`

- 顶部统计卡片行：学习课程数、知识笔记数、待复习错题数
- 课程列表：卡片式，每项显示名称、学期、掌握度进度条
- 底部新建课程按钮

### 课程工作台 `/course/:slug`

**顶部栏**：
- 课程名称 + 描述信息
- 功能 Tab 切换（问答/笔记/图谱/错题）
- 课程掌握度进度条（shimmer 动画）+ 百分比

**问答 Tab**：复用 ChatPage 组件，传入 courseId；AI 回答底部带引用标注（📖 文件名 + 章节 + 页码）；回答后可一键生成笔记

**笔记 Tab**：
- 搜索栏 + 双列卡片网格
- 每张卡片：标题、内容摘要、掌握度标签、来源（自动生成/手动创建）、时间
- 新建笔记入口（虚线卡片）
- 支持展开查看完整内容

**知识图谱 Tab**：
- D3 力导向图 SVG 渲染
- 节点大小表示重要程度
- 节点颜色表示掌握度（绿=已掌握/紫=学习中/灰=未学）
- 支持缩放拖拽，点击节点跳转对应知识点的问答

**错题本 Tab**：
- 红色左边框卡片
- 每张卡片：知识点标签、题目、错误答案（红）、正确答案（绿）、日期
- 手动添加入口

### 通用对话 `/chat`

- 复用聊天组件，不传 courseId
- 顶部提示：当前为通用对话模式
- AI 回答中标注"非课程上下文"

### 知识库管理 `/knowledge`

- 拖拽上传区域（支持 pdf/pptx/docx/epub/xlsx/csv/txt/md）
- 文件列表：图标 + 文件名 + 大小 + 解析知识点数 + 关联课程 + 索引状态
- 状态标签：已索引（绿）/ 解析中（黄）

### 设置 `/settings`

- 左侧分类导航：通用/模型设置/技能管理/知识库/关于
- 右侧设置表单
- 技能管理从此页进入（替代原独立 SkillsPage）

## 组件层级

```
App
├── IconNav (全局图标导航 + 主题切换)
├── Sidebar (课程列表 + 子导航 + 底部链接)
│   └── CourseList → CourseItem → SubNav
└── Main
    ├── TopHeader (面包屑/课程标题/进度条 — 按页面不同)
    └── Content
        ├── HomePage (统计卡片 + 课程列表)
        ├── CoursePage (Tab 容器)
        │   ├── ChatView (问答)
        │   ├── NotesView (笔记网格)
        │   ├── KnowledgeGraph (力导向图)
        │   └── WrongAnswersView (错题列表)
        ├── ChatPage (通用对话)
        ├── KnowledgePage (知识库管理)
        └── SettingsPage (设置面板)
```

## UI 组件库

保留 shadcn/ui（Button, Input, Textarea, Badge, Card, ScrollArea, Tooltip, Sheet, DropdownMenu, Separator, Accordion），统一样式变量接入主题系统。

## 实现要点

1. CSS 变量驱动主题切换（`[data-theme="light"]`），全局单次切换，所有组件自动响应
2. 暗色/亮色两套 accent 色系独立，不改 CSS 结构只改变量
3. 图标导航栏固定在 52px，侧栏宽度可拖拽（52-400px）
4. 课程选中态关联子导航展开，路由参数为 course slug
5. 知识点卡片 hover 动效用 CSS only（::before + transform），不动 JS
6. 知识图谱用 D3 force simulation，节点颜色/大小数据驱动

## 与现有功能 spec 的关系

本设计文档是 `2026-06-11-coursemate-redesign-design.md` 的视觉/交互补充。功能架构、API 设计、数据库变更以后者为准；本 spec 覆盖前端 UI/UX 的所有视觉决策。
